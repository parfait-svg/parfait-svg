<!-- ===================== ABOUT ===================== -->
<p align="left">
  <img src="https://img.shields.io/badge/-ABOUT%20ME-black?style=for-the-badge&logo=aboutdotme&logoColor=white&labelColor=ec1313&color=1e1e2f" />
</p>

I am a software engineering student (Level 3 at CITEC-HITM) and a full-stack web and mobile developer based in Cameroon. My work centres on building structured, scalable and efficient digital systems — web platforms, e-commerce solutions, mobile applications, and the backend architectures that hold them together.

What drives me is solving **real, practical problems** rather than reproducing tutorial templates. I am most comfortable taking an idea from an empty folder all the way to a deployed, working product: shaping the data model, writing the backend logic and APIs, building the interface, wiring in third-party and AI services, and finally shipping something that people can actually use. I care as much about how a system is built as about whether it runs — clean structure, readable code, and deployments that can be handed off without a struggle.

A large part of my growth has come from building for real contexts. I co-founded **Brantrix Technology**, a software agency delivering web and mobile solutions for African businesses, which keeps me working against real clients, real deadlines and real constraints rather than imaginary ones. That experience has taught me that the hard part of software is rarely the first version — it is making something maintainable, affordable to run, and genuinely useful in the environment it is deployed into, where connectivity, budgets and devices are not always ideal.

As a developer I am continuously learning. I treat every project as a chance to sharpen my understanding of architecture, performance and security, and I pay close attention to the parts of engineering that are easy to skip but expensive to ignore: authentication, data integrity, error handling, documentation and deployment. My long-term goal is to build reliable products and platforms that serve users across Cameroon and the wider African market.

<!-- ===================== HOW I WORK ===================== -->
<p align="left">
  <img src="https://img.shields.io/badge/-HOW%20I%20WORK-black?style=for-the-badge&logo=gitbook&logoColor=white&labelColor=ec1313&color=1e1e2f" />
</p>

- **Structure before speed.** I plan the data model and the flow of a system before writing features, so the foundation can carry what is built on top of it.
- **Clean, readable code.** I write for the next developer — and for my future self — favouring clarity and maintainability over clever shortcuts.
- **Separation of concerns.** Frontend, backend, data access and configuration are kept distinct, so each part can change without breaking the others.
- **Security as a default, not an afterthought.** Hashed credentials, token-based authentication, role-based access and careful handling of secrets are part of the build, not a later patch.
- **Reproducible deployments.** I aim for systems that deploy the same way every time and are genuinely easy to hand off, rather than fragile setups that only run on one machine.
- **Documentation that matters.** Clear READMEs, API docs and setup notes, so a project can be understood and continued by someone else.
